# Spoofer 2.2.0

## Included

- Console executable named `Spoofer.exe`
- Local-only Flask service
- Roblox animation download and upload workflow
- HTTPS update manifest support
- SHA-256 verification before updates
- User confirmation before an update is installed
- Improved local validation, retries, logging, and error handling

## Installation

Keep `Spoofer.exe`, `config.json`, and `Maiks_Spoofer_Plugin.lua` available on
the same machine. See `README.txt` for setup instructions.

## Security

Keep `config.json` private. It contains sensitive Roblox credentials.
